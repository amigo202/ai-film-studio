# AI Film Studio & Director Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/amigo202/ai-film-studio)

A high-end, cinematic portfolio website for an **AI Film Studio & Creative Director**, built with React, Vite, Tailwind CSS, Supabase backend support, and an intuitive 7-step Studio Project Builder CMS.

## Features
- **Cinematic A24 Aesthetic**: Deep Obsidian black, Film Grain texture, Widescreen 2.39:1 / 16:9 aspect ratios, responsive typography.
- **3-Tier Video Architecture**: Static Poster (Instant Load) -> 5-8s Preview Loop (Muted) -> Cinema Master (Vimeo, YouTube, Bunny, Direct).
- **8-Stage Behind The Film**: Interactive production pipeline breakdown (Concept, Visual Dev, LoRA Consistency, AI Frames, Motion, Editing, Sound, Master).
- **Frame Evolution Visualizer**: 4-stage shot progression (Initial Idea -> Generated Frame -> Motion -> Final Film).
- **Production Data & Credits**: Metrics counters & filmography roster.
- **Studio CMS (`/admin`)**: 7-stage Project Builder with draft autosave and live preview.
- **SEO & OpenGraph Pre-rendering**: Static HTML snapshots for social sharing on WhatsApp, LinkedIn, and Google.
